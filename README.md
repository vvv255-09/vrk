# 📦 Warehouse Management System

Система автоматизации торговой деятельности и управления складом. Позволяет вести полный учет товаров, контролировать остатки, оформлять заказы, отслеживать финансовые расходы и управлять пользователями.

## 🚀 Основные возможности

- **Управление складом**: Каталог товаров, мониторинг критического остатка, учет поступлений от поставщиков.
- **Продажи и заказы**: Оформление заказов, генерация чеков, история покупок.
- **Финансовый учет**: Регистрация расходов и списаний товаров.
- **Администрирование**: Управление пользователями и правами доступа.
- **Аналитика**: История всех операций и отчеты по товарам.

## 🛠 Технологический стек

- **Язык:** Java 21
- **Интерфейс:** JavaFX (FXML, CSS)
- **База данных:** MySQL 8.0+
- **Сборка:** Maven

## ⏱ Быстрый старт

### Требования
- JDK 21
- Maven 3.x
- MySQL Server

### Запуск
1. Настройте базу данных MySQL (подробности в [docs/setup.md](docs/setup.md)).
2. Склонируйте репозиторий.
3. Запустите приложение через Maven:
   ```bash
   mvn javafx:run
   ```

## 📁 Структура проекта
- `src/main/java` — Исходный код (MVC: Модели, Контроллеры, Слой данных).
- `src/main/resources` — FXML-разметка интерфейса и стили CSS.
- `docs/` — Подробная техническая и пользовательская документация.
